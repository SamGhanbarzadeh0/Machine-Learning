# Data directory

Keep downloaded files here. Notebook 06 checks the Dermatology file, the two NHANES development CSVs and the official later-cycle XPORT files. If a download fails, place the exact source file in `Data` or `Data/NHANES` as specified in the notebook. See [DATA_SOURCES.md](../../DATA_SOURCES.md) for links and terms of use. Do not commit raw datasets or checkpoints.
