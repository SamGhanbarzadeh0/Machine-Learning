# Results

The [November 2026 benchmark](Benchmark) contains six reports:

| File | Contents |
|---|---|
| [benchmark_metrics.json](Benchmark/benchmark_metrics.json) | Held-out classification and regression scores, solver diagnostics and figure references |
| [comprehensive_validation.json](Benchmark/comprehensive_validation.json) | Analytical checks, sensitivity analyses and development-set experiments |
| [nhanes_cross_validation.json](Benchmark/nhanes_cross_validation.json) | Five-fold and pooled out-of-fold regression results |
| [nhanes_temporal_validation.json](Benchmark/nhanes_temporal_validation.json) | Evaluation on the 2021–2023 NHANES cycle |
| [sklearn_comparison.json](Benchmark/sklearn_comparison.json) | Agreement with scikit-learn and computational timing |
| [validation_status.json](Benchmark/validation_status.json) | Completed evaluation stages and report references |

The earlier [NHANES baseline](nhanes_baseline.json) is used for comparison in notebook 06.
